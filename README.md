# 🍽️ Restaurant Tips Analysis Dashboard

## 📊 Project Overview
This project presents an interactive Power BI dashboard built using the Restaurant Tips dataset. It analyzes customer tipping behavior, dining patterns, and restaurant revenue while providing meaningful business insights.

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- CSV Dataset

## 📈 Dashboard Features
- KPI Cards (Average Tip, Average Bill, Predicted Bill, Total Customers, Total Revenue)
- Average Bill by Time
- Average Bill by Day
- Average Bill by Gender
- Average Bill by Smoker
- Actual Bill vs Predicted Bill (Regression Analysis)
- Model Evaluation Metrics (R² Score, MAE, MSE)
- Business Insights Panel
- Interactive Slicers

## 💡 Key Insights
- Dinner customers spend more on average than lunch customers.
- Weekend customers have higher average bills.
- Female customers have a slightly higher average bill than male customers.
- Non-smokers have a slightly higher average bill than smokers.
- The regression model achieved an R² score of 0.58, showing moderate predictive performance.
